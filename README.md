## Temas Cubiertos

Durante este curso se abordan herramientas y técnicas para el procesamiento, análisis espacial y automatización de información geográfica:

* **Automatización GIS:** Ejecución de procesamiento espacial silencioso (*headless*) utilizando la API de PyQGIS en entorno Linux.
* **Control de Calidad e Integridad de Datos:** Inspección de referencias espaciales (CRS), validación topológica de geometrías y métricas tabulares mediante GeoPandas y Pandas.
* **Procesamiento Vectorial en Lote:** Procesamiento recursivo de archivos vectoriales (.shp, .gpkg, .geojson) con manejo de excepciones y estructura de directorios.

Cada repositorio individual contiene la documentación específica del código, dependencias del sistema, instrucciones de ejecución y descripción detallada de entradas y salidas.
